# Contributors

Public credit is part of the SokoFlow model. Everyone who leads, owns, or
materially improves a part of this project is listed here — visibly and
permanently, in the history of this repository.

Role entries are added as soon as an agreement is made, not when code lands.
Everyone on this list is entitled to be listed however they wish; tell us how
you want to appear and we will update it.

## What each role means

- **Module lead / maintainer** — owns the design and rules for that module.
  Credit is automatic, visible, and permanent. The revenue-share framework is
  described in [docs/REVENUE-SHARE.md](docs/REVENUE-SHARE.md) (draft).

## Adding someone

Open a pull request with the person's name, role, scope, and their preferred
contact. If they have not agreed, the pull request must be raised with them
first. Credit is never given without consent.
